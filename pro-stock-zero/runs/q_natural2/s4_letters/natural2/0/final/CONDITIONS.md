# Conditions for the complaint reply task

Source: user request in this session (task: reply to `klacht1.txt`, write to `antwoord1.txt`).

1. Write the reply in `antwoord1.txt`, in Dutch.
   - Reason: the customer writes in Dutch and the reply is for them.
2. At most 100 words, counting every whitespace-separated token.
3. Address the customer formally (u/uw). Never use je, jij, or jouw.
4. Mention the order number (NL-7731).
5. Offer a replacement lamp, shipped free of charge.
6. Never mention or promise a refund (`terugbetaling`, `terugbetalen`, `geld terug`).
   - Reason: refunds are decided by the shop manager, not by us.
7. Do not use the words `sorry` or `excuses`.
8. The last line is exactly `Team Klantendienst`.

## Second reply task (`klacht2.txt` -> `antwoord2.txt`)

Source: user request in this session: "Write our answer in `antwoord2.txt`, following the same requirements as our first reply."

The same rules 1-8 above apply to `antwoord2.txt`, including the reasons given for each.
